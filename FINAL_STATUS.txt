⚙️ INSTALLATION MODEL
─────────────────────────────────────────────────────────────────────────────
Full Installation Time:       15-25 minutes (dominated by downloads)
Execution:                    Sequential — one module at a time

Why Sequential:
  • 00-base-system runs first (required: kernel, build tools)
  • Then 01-05 run in order (i3, docker, security, power, network)
  • Then 06-07-08 run (dotfiles, finalization, docs)
  • Only one process may hold the dpkg/apt lock — running modules
    concurrently would make apt-get fail. setup.sh calls wait_for_apt_lock
    before each module.

Resilient package install: if an apt batch fails (e.g. a package name differs
across Debian releases), ensure_pkgs retries each package individually so the
available ones still install.
